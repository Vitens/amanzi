# Add and connect units

Put process blocks on the canvas and wire product, waste, and flush streams so the scenario can calculate.

## Content to write

- Add from the library: drag onto the canvas, or double-click to drop and auto-connect.
- Library groups: **Main stream** vs **Waste stream**.
- Every scenario needs a source (abstraction) and a sink (output).
- Connect by dragging between anchors: **product** (blue), **waste** (red), **flush / backwash** (dotted blue).
- Validation messages: missing source/sink; “The model … is not fully connected”.
- Duplicate connections are removed automatically.
- Zoom, pan, zoom-to-fit; grid is visual only.
