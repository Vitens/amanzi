# Configure a unit

Open a block, change its parameters, and reset to defaults when needed.

## Content to write

- Open: double-click the block, or the edit-parameters control.
- Categories in the form (design, operational, chemicals, hydraulic line — as the UI labels them).
- Changes apply after a short pause; design graphs and tables in the dialog update together with the plant-wide sidebar.
- Reset to default for that unit.
- Conditional fields (example: circular vs rectangular filter dimensions) appear only when the parent choice matches.
- Where to look up allowed ranges: [process units](../reference/process-units/index.md), not this page.
