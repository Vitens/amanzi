# Work with micropollutants

Add PFAS, VOC, or other custom micropollutants on abstraction, and see where those concentrations are used downstream.

## Content to write

- Open Abstraction (groundwater) → composition / micropollutants.
- Lists: PFAS, VOC, Other; adding a compound and a concentration with the unit the form shows.
- Those values travel with the water as extra measurements (they are not the same as the ion list).
- Where they matter next: activated carbon design (PFAS isotherms, Sum4/Sum20/PEQ); tower aeration (VOC stripping).
- Custom compounds in scenario metadata vs built-in names.
- Plant-wide quality walk currently does **not** apply GAC PFAS removal — see [Limitations](../reference/limitations.md). Use design view for GAC breakthrough.
