# Compare in the report

Build the project report for one scenario or for all scenarios side by side.

## Content to write

- **Calculate project** / open Report.
- Single-scenario: charts and tables for quantity, quality, energy, sustainability.
- Multi-scenario: comparison of the same families across tabs.
- Switching the selected scenario inside the report without losing the comparison.
- What is *not* in the report (per-element membrane DataFrames live in design view).
- Export/print only if the UI offers it; otherwise download the project JSON as the record of inputs.
