# Trinkwasseraufbereitung

Grundwasser wird durch eine Reihe von Schritten zu Trinkwasser. Alltagssprache; kein Anlagendesign-Kurs.

## Inhalt zum Schreiben

- Grundwasser enthält bereits gelöste Stoffe (Eisen, Härte, Methan, manchmal PFAS).
- Eine **Aufbereitungsstrecke** ist eine Folge von Räumen/Maschinen, die jeweils eine Aufgabe erledigen (belüften, filtrieren, enthärten, dosieren, Membran, Kohle).
- **Produktwasser** geht Richtung Zapfhahn; **Abfall** ist Konzentrat oder Schlammwasser, das nicht als Trinkwasser abgegeben werden kann; **Rückspülung** ist Waschwasser von Filtern.
- Warum eine Zeichnung aus Kästen und Pfeilen ein nützliches Modell dieser Strecke ist.
- Die Bibliothek von Amanzi ist diese Menge an Kästen für ein typisches niederländisches Grundwasserwerk — nicht jeder Prozess auf der Erde.
