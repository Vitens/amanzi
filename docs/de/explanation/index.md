# Erläuterung

Dieser Abschnitt dient dem Verständnis. Die **Einführungs**-Seiten sind für Menschen neu in der Trinkwasseraufbereitung. Die **Wissenschafts**-Seiten sind für Schlüsselanwender, die Modelle, Annahmen und Literatur wollen.

Es gibt keine vorgeschriebene Lesereihenfolge, aber ein nützlicher Kreislauf ist: eine Anleitung ausprobieren → eine Handlungsanleitung ausführen → eine Tatsache nachschlagen → hierherkommen für das Warum.

## Regeln für diesen Abschnitt

- Erörtern, vergleichen und zitieren. Keine Klick-für-Klick-Schritte.
- Literatur gehört hierher, nicht in Anleitungen oder Handlungsanleitungen.
- Diagramme: Mermaid-Skizzen von Prozessen und Berechnungen.
