# Was Amanzi ist

Amanzi dient dem **Entwerfen und Vergleichen von Aufbereitungsszenarien**, nicht dem Betreiben einer Live-Anlage.

## Inhalt zum Schreiben

- Wer es gebaut hat (Vitens) und warum Szenarioarbeit ohne gemeinsame Zeichnung + Berechnung schwer ist.
- Was Sie bekommen: ein Fließschema, mehrere Was-wäre-wenn, Zahlen für Menge, Qualität, Energie, Chemikalien, CO₂.
- Was es **nicht** ist: SCADA, ein Labor, ein rechtsverbindlicher Entwurf, ein Zeitreihen-Digitaler-Zwilling.
- Browser-Engine (Pyodide) vs gehostete Demo: dieselbe Idee, kein Server auf Ihrem Schreibtisch.
- GPL-3.0 und Zitieren der Software (Info-Dialog) — ein Absatz, Link zur Lizenz.
- Wie das zu den vier Dokumentationstypen passt (wiederholen Sie die Anleitungen nicht).
