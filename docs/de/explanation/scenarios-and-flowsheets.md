# Szenarien und Fließschemata

Die Zeichenfläche ist ein **Stoffbilanzmodell**. Register sind **Was-wäre-wenn-Versionen**, nicht verschiedene Wochentage.

## Inhalt zum Schreiben

- Ein Fließschema sagt: so viel Wasser dieser Qualität tritt hier ein, diese Einheiten ändern es, so viel verlässt als Produkt oder Abfall.
- Stationärer Zustand: ein Betriebspunkt (min/nom/max Kapazitäten), keine 24-Stunden-Animation.
- Positionen auf der Zeichenfläche sind für Menschen; die Hydraulik nutzt Höhen und Verluste, die Sie eingeben, nicht den Zeichenmaßstab.
- Mehrere Szenarien = Entwürfe vergleichen (zusätzliche GAC vs zusätzliche Belüftung), nicht „Montag vs Dienstag“.
- Die JSON-Projektdatei *ist* das Modell; die UI ist der Editor.
