# Eine Sache ändern

Bearbeiten Sie einen offensichtlichen Parameter an einer Einheit, beobachten Sie, wie sich die Zahlen in der Seitenleiste bewegen, und machen Sie es dann rückgängig.

## Inhalt zum Schreiben

- Doppelklicken Sie einen Aufbereitungsblock (oder nutzen Sie Bearbeiten), um die Konfiguration zu öffnen.
- Ändern Sie ein beschriftetes Feld, das die Demo bereits ausgefüllt hat (Kapazität oder eine einfache Effizienz) — keine Freundlich-Koeffizienten oder Ionenlisten.
- Beobachten Sie die rechte Seitenleiste und alle offenen Entwurfsdiagramme; Amanzi berechnet nach einer kurzen Pause neu.
- Nutzen Sie Rückgängig, um die Demo zurückzusetzen.
- Verweisen Sie auf [Eine Einheit konfigurieren](../how-to/configure-a-unit.md) für andere Felder und auf [Wasserqualität lesen](../explanation/reading-water-quality.md), wenn ein Qualitätsname verwirrend ist.
