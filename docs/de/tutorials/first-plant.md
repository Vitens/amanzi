# Ihre erste Anlage

Gehen Sie das Demo-Projekt durch: Wasser kommt aus einer Quelle, passiert Aufbereitungsblöcke und verlässt die Anlage an einem Auslass. Werfen Sie einen Blick auf die Ergebnisleiste. Kein Chemievortrag.

## Inhalt zum Schreiben

- Jedes Szenario braucht eine **Quelle** (Gewinnen) und eine **Senke** (Lieferung). Die Demo hat beides bereits.
- Folgen Sie dem **Produkt**-Pfad (blau) von links nach rechts; erwähnen Sie **Abfall** (rot) und **Spülung / Rückspülung** (gepunktet) nur als „andere Leitungen, die Sie sehen werden“.
- Klicken Sie einen Block an, damit die rechte Seitenleiste Zahlen zeigt; bearbeiten Sie noch nichts.
- Ergebnisfamilien, die Sie wahrnehmen sollten, jeweils in einem Satz: Menge (wie viel Wasser), Qualität (was darin ist), Energie, Chemikalien, Nachhaltigkeit (CO₂).
- Wenn die Zeichenfläche rot aussieht oder „nicht vollständig verbunden“, ist das ein Verdrahtungsproblem — heben Sie die Behebung für die Handlungsanleitung auf.
