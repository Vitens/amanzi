# Anleitungen

Dieser Abschnitt lehrt durch Handeln. Arbeiten Sie im **Demo-Projekt**, das Amanzi für Sie öffnet. Beginnen Sie nicht mit einer leeren Zeichenfläche und erfinden Sie keine Grundwasseranalyse.

Die In-App-Anleitung (Hilfe → Tutorial) ist eine optionale Ergänzung mit kurzen Videos derselben ersten Schritte. Diese Seiten benennen, was Sie sehen, und was Sie als Nächstes ausprobieren können.

## Regeln für diesen Abschnitt

- Ein erfolgreicher Hauptweg pro Seite; keine Nebenaufgaben.
- Nur Demo-Daten.
- Keine Literatur, keine Parameterlisten, keine Chemievorträge.
- Diagramme: Mermaid-Wireframes der Oberfläche, keine Screenshots.

## Seiten

- [Amanzi öffnen](open-amanzi.md) — starten Sie die App und benennen Sie die Hauptbereiche der Oberfläche.
- [Ihre erste Anlage](first-plant.md) — gehen Sie das Demo-Fließschema durch und werfen Sie einen Blick auf die Ergebnisse.
- [Eine Sache ändern](change-one-thing.md) — bearbeiten Sie einen Parameter und beobachten Sie, wie sich Zahlen bewegen.
- [Szenarien vergleichen](compare-scenarios.md) — ein zweites Was-wäre-wenn und der Bericht.
- [Ihre Arbeit speichern](save-your-work.md) — Ihr Projekt ist eine Datei, kein Konto.

## Inhalt zum Schreiben

- Wie Sie diesen Abschnitt nutzen (zuerst Demo, In-App-Anleitung als optionale Ergänzung).
- Empfohlene Reihenfolge der fünf Anleitungen.
- Was Sie *hier nicht* erwarten sollten (Theorie steht in der Erläuterung; Parameterlisten stehen in der Referenz).
