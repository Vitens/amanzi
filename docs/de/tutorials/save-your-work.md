# Ihre Arbeit speichern

Ihre Arbeit ist eine **Projektdatei**, kein Konto. Laden Sie sie herunter, wenn Sie sie morgen oder auf einem anderen Computer brauchen.

## Inhalt zum Schreiben

- Der Browser behält eine lokale Kopie, solange der Tab in Gebrauch ist; das ist kein Backup.
- **Herunterladen** schreibt eine `.json`-Datei mit dem Namen des Projekts.
- **Hochladen** ersetzt das, was auf dem Bildschirm ist, durch diese Datei.
- Sie können die Datei per E-Mail senden; ein Kollege öffnet sie auf dieselbe Weise in Amanzi.
- Wenn Amanzi sagt, die Datei wurde auf eine neuere Version aktualisiert, ist das erwartbar, wenn Versionen abweichen — Details in [Speichern, laden, herunterladen](../how-to/save-load-download.md).
