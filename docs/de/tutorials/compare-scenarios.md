# Szenarien vergleichen

Ein Szenario ist eine Version der Anlage. Erstellen Sie eine zweite Version, ändern Sie eine Entwurfswahl und öffnen Sie den Bericht.

## Inhalt zum Schreiben

- Die Szenario-Register sitzen unten; `+` erzeugt ein weiteres Szenario.
- Kopieren Sie die Demo-Idee: behalten Sie dasselbe Layout, ändern Sie einen Block oder eine Zahl, damit die beiden Register vergleichbar sind.
- Notizen zu einem Szenario (v1.0.5) sind für Sie selbst; sie ändern die Berechnung nicht.
- **Projekt berechnen** / Bericht: betrachten Sie den Vergleich von Menge, Qualität, Energie und Nachhaltigkeit über die Register hinweg.
- Erklären Sie hier nicht, wie CO₂ berechnet wird — das steht in [Menge, Energie, Chemikalien, CO₂](../explanation/quantity-energy-chemicals-co2.md).
