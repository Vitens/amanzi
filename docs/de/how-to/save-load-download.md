# Speichern, laden, herunterladen

Behalten Sie ein Projekt im Browser, laden Sie es als JSON herunter oder ersetzen Sie das aktuelle Projekt durch Hochladen einer Datei.

## Inhalt zum Schreiben

- Menüaktionen: speichern / herunterladen / hochladen / zurücksetzen (Beschriftungen aus dem Projektmenü).
- Browser-Speicher vs heruntergeladene `.json`: Speicher ist praktisch; die Datei ist die Kopie, die Sie teilen können.
- Hochladen **ersetzt** das geöffnete Projekt; warnen Sie vor dem Überschreiben ungespeicherter Änderungen, falls die UI das tut.
- Versionsmigrations-Hinweis: Dateiformat aktualisiert; was dem Nutzer zu sagen ist (sicher fortfahren; Versionsbereich notieren).
- Benennen Sie das Projekt in der oberen Leiste um, damit der heruntergeladene Dateiname passt.
