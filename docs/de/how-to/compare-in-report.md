# Im Bericht vergleichen

Erstellen Sie den Projektbericht für ein Szenario oder für alle Szenarien nebeneinander.

## Inhalt zum Schreiben

- **Projekt berechnen** / Bericht öffnen.
- Einzelszenario: Diagramme und Tabellen für Menge, Qualität, Energie, Nachhaltigkeit.
- Mehrere Szenarien: Vergleich derselben Familien über die Register hinweg.
- Wechseln des ausgewählten Szenarios im Bericht, ohne den Vergleich zu verlieren.
- Was *nicht* im Bericht steht (Membran-DataFrames pro Element leben in der Entwurfsansicht).
- Export/Druck nur, wenn die UI es anbietet; andernfalls laden Sie die Projekt-JSON als Aufzeichnung der Eingaben herunter.
