# Kennzahlen festlegen

Legen Sie projektweite (und optionale Szenario-) Zahlen fest, die viele Berechnungen teilen: Emissionsfaktoren, PFAS-Grenzwerte und ähnliche Nachschlagewerte.

## Inhalt zum Schreiben

- Öffnen Sie den Tab **Kennzahlen** in der rechten Seitenleiste (und den Kennzahlen-Dialog aus der oberen Leiste).
- Überschreibungen auf Projektebene vs Szenarioebene: wann ein Szenario abweichen sollte.
- Wann Sie einen Wert anfassen: CO₂-Annahmen vergleichen oder einen regulatorischen Sum4-/Sum20-/PEQ-Grenzwert abgleichen — nicht für das alltägliche Zeichnen des Fließschemas.
- Suchen/Filtern in der Kennzahlenliste.
- Den eingebauten Datenbankwert für eine Zeile wiederherstellen.
- Fakten zur Datenbank selbst: [Kennzahlen](../reference/key-figures.md).
