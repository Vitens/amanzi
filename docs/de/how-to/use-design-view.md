# Entwurfsansicht nutzen

Öffnen Sie den Entwurfsdialog pro Einheit (Diagramme und Tabellen für diesen Block) gegenüber dem Durchrechnen der ganzen Anlage.

## Inhalt zum Schreiben

- Anlagenweite Lösung (Seitenleiste) vs Entwurfsansicht (Diagramme/Tabellen einer Einheit).
- Wie Sie den Entwurf für den ausgewählten Block öffnen.
- Wechseln des in der Entwurfsansicht gezeigten Modells (v1.0.5).
- Entwurf kann reichhaltigere Physik zeigen als der Live-Anlagenlauf — besonders Aktivkohlefiltration / PFAS; verweisen Sie auf [Einschränkungen](../reference/limitations.md) und [Aktivkohle und PFAS](../explanation/activated-carbon-and-pfas.md).
- Hydraulische Leitung und Stoffbilanz-Tabellen wie im Dialog beschriftet.
- Schließen Sie den Entwurf und bestätigen Sie, dass die Zeichenfläche noch dem Szenario entspricht, das Sie bearbeiten wollten.
