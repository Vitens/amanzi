# Eine Einheit konfigurieren

Öffnen Sie einen Block, ändern Sie seine Parameter und setzen Sie bei Bedarf auf Standardwerte zurück.

## Inhalt zum Schreiben

- Öffnen: Doppelklick auf den Block oder die Steuerung zum Bearbeiten der Parameter.
- Kategorien im Formular (Entwurf, Betrieb, Chemikalien, hydraulische Leitung — wie die UI sie beschriftet).
- Änderungen greifen nach einer kurzen Pause; Entwurfsdiagramme und Tabellen im Dialog aktualisieren sich zusammen mit der anlagenweiten Seitenleiste.
- Auf Standard für diese Einheit zurücksetzen.
- Bedingte Felder (Beispiel: runde vs rechteckige Filterabmessungen) erscheinen nur, wenn die übergeordnete Wahl passt.
- Wo erlaubte Bereiche nachzuschlagen sind: [Prozesseinheiten](../reference/process-units/index.md), nicht diese Seite.
