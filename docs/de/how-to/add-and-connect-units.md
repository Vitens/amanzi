# Einheiten hinzufügen und verbinden

Setzen Sie Prozessblöcke auf die Zeichenfläche und verdrahten Sie Produkt-, Abfall- und Spülströme, damit das Szenario rechnen kann.

## Inhalt zum Schreiben

- Hinzufügen aus der Bibliothek: auf die Zeichenfläche ziehen oder doppelklicken zum Ablegen und automatischen Verbinden.
- Bibliotheksgruppen: **Hauptstrom** vs **Abfallstrom**.
- Jedes Szenario braucht eine Quelle (Gewinnen) und eine Senke (Lieferung).
- Verbinden durch Ziehen zwischen Ankern: **Produkt** (blau), **Abfall** (rot), **Spülung / Rückspülung** (gepunktet blau).
- Validierungsmeldungen: fehlende Quelle/Senke; „The model … is not fully connected“.
- Doppelte Verbindungen werden automatisch entfernt.
- Zoomen, Schwenken, Zoom auf alles; das Raster ist nur visuell.
