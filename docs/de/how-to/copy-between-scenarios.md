# Zwischen Szenarien kopieren

Kopieren und fügen Sie Blöcke zwischen Szenario-Registern ein und hängen Sie Notizen an ein Szenario.

## Inhalt zum Schreiben

- Wählen Sie einen oder mehrere Blöcke; `Ctrl+C` / `Ctrl+V` (auf macOS mit dem üblichen Modifikator).
- Duplizieren auf derselben Zeichenfläche vs Einfügen in ein anderes Szenario-Register.
- Verbindungen: was mit dem Block kopiert wird und was Sie neu verdrahten müssen.
- Szenario-Notizen (v1.0.5): hinzufügen, bearbeiten, sie beeinflussen die Solver nicht.
- Ein Szenario-Register umbenennen oder löschen; Sie können das Projekt nicht mit null Szenarien verlassen, falls die UI das verbietet — dokumentieren Sie die tatsächliche Regel.
