# Sprache wechseln

Stellen Sie die Benutzeroberfläche auf Englisch, Niederländisch, Deutsch oder Französisch ein.

## Inhalt zum Schreiben

- Wo die Sprachsteuerung ist (und dass die Voreinstellung der Browsersprache folgt).
- Die vier Locales: `en`, `nl`, `de`, `fr`.
- Was wechselt: Bibliotheksnamen, Formularbeschriftungen, Anleitungstext, Info-Dialog.
- Diese Dokumentationsseite hat dieselben vier Sprachen (Englisch, Niederländisch, Deutsch, Französisch) über eine eigene Sprachauswahl. Es ist eine separate Kopie der Seiten, nicht der JSON-Katalog der App.
- Was **nicht** wechselt: Projekt-JSON-Feldnamen, Kennzahlen-Schlüssel. Die Architekturdokumentation bleibt Englisch.
- Einige Einheitsnamen bleiben gemischt (Beispiel: Pellet softening kann als „Pelletontharding“ erscheinen).
