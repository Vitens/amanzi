## Regeln für diesen Abschnitt

- Angeben, was etwas ist, was es akzeptiert, was es zeigt.
- Keine Klick-für-Klick-Verfahren und keine Literatur.
- Parametergruppen kommen aus der parametrischen Definition der Einheit; Tabellen später aus YAML füllen, hier keine Bereiche erfinden.
