# Glossar

Kurze Definitionen. Keine Essays.

## Inhalt zum Schreiben

- **Szenario** — eine Version der Anlage innerhalb eines Projekts.
- **Projekt** — JSON-Datei mit einem oder mehreren Szenarien.
- **Fließschema / Zeichenfläche** — die Zeichnung von Einheiten und Strömen.
- **Kennzahl** — geteilter Nachschlagewert (Emissionsfaktor, Grenzwert, Wirkungsgrad).
- **Gewinnen** — Grundwasserquellen-Block.
- **Produkt / Abfall / Spülung** — die drei Stromtypen.
- **Rückspülung** — Waschen eines Filterbetts; oft ein Spülstrom.
- **EBCT** — empty bed contact time (GAC).
- **BV** — bed volumes.
- **GAC** — granular activated carbon.
- **RQ** — Luft-Wasser-Verhältnis (Belüftung).
- **SI** — Sättigungsindex (Calcit, sofern nicht anders angegeben).
- **CCPP / TACC₉₀** — Calciumcarbonat-Fällungspotenzial / zugehörige UI-Beschriftung.
- **PHREEQC** — die Chemie-Engine, die Amanzi nutzt.
- **PFAS** — per- und polyfluorierte Alkylsubstanzen.
- **Sum4 / Sum20 / PEQ** — gruppierte PFAS-Kennzahlen (Grenzwerte aus Kennzahlen).
- **VOC** — flüchtige organische Verbindungen (extraneous-Liste).
- **RO / NF** — Umkehrosmose / Nanofiltration.
- **Kw** — Membran-Wasserdurchlässigkeit.
- **HTU / NTU** — Höhe / Anzahl der Transferunits (Füllkörper-Turm).
- **Freundlich K, 1/n** — Isothermenparameter; 1/n ist der Exponent.
- **SRS** — Sheindorf–Rebhun–Sheintuch kompetitive Freundlich.
- **Pelletontharding** — Calcit-Pelletreaktor (UI kann Pelletontharding sagen).
