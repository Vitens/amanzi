# Benutzeroberfläche

Benannte Teile des Amanzi-Fensters.

## Inhalt zum Schreiben

- **Obere Leiste:** Projektname, umbenennen, herunterladen/hochladen/speichern/zurücksetzen, Projekt berechnen, Zoom auf alles, Kennzahlen, Sprache, Anleitung, Info, Feedback.
- **Bibliothek (links):** Gruppen Hauptstrom vs Abfallstrom; Filtern/Suchen; Raster vs Liste falls vorhanden.
- **Zeichenfläche:** schwenken, zoomen, Raster; Blockpositionen sind nur Layout (keine Geografie).
- **Ergebnis-Seitenleiste (rechts):** Tabs Menge, Qualität, Energie, Nachhaltigkeit; Tab Kennzahlen.
- **Szenario-Register (unten):** hinzufügen, umbenennen, löschen, Notizen.
- **Einheitendialoge:** Konfigurationsformular, Entwurfsdiagramme/-tabellen, hydraulische Leitung.
- **Berichtsdialog:** Einzel- und Mehrfachszenario.
- **Info:** Lizenz (GPL-3.0), Danksagungen (PHREEQC, PhreeqPython, Vue, Element Plus), Zitat.
- **Init-Dialog:** Fortschritt beim Laden der Engine.
