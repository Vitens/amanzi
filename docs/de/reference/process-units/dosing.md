# Dosierung

Bibliotheksname: **Dosierung**. Fügt eine Chemikalie mit konstanter Dosis hinzu oder steuert einen Sollwert an.

## Wann platzieren

Sie dosieren CO₂, Säure, Lauge, Kalk, Calcit, Sauerstoff, FeCl₃ oder MnCl₂ auf dem Hauptstrom.

## Ströme

- Ein/Aus: Produkt.

## Eingaben (UI-Gruppen)

- **Position:** Zulauf oder Ablauf des Blocks.
- **Chemikalie:** `co2`, `hcl`, `h2so4`, `lye`, `lime`, `calcite`, `oxygen`, `iron_chloride`, `manganese_chloride`.
- **Modus:** konstant (mmol/L) oder Sollwert (pH, SI, AggCO₂, CCPP90).

## Ausgaben / Entwurfstabellen

- Dosierantwortkurven in der Entwurfsansicht.
- Chemikalienmasse und zugehörige Nachhaltigkeit (Emissionsfaktoren aus Kennzahlen).
