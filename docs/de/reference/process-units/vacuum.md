# Vakuum-Entgasung

Bibliotheksname: **Vakuum-Entgasung**. Einstufiger Vakuumstripper (kein Membrankontaktor).

## Wann platzieren

Sie entgasen durch Absenken des Gasphasendrucks an einem Behälter und wollen pH / SI / Gaszusammensetzung vs Vakuum.

## Ströme

- Ein/Aus: Produkt.

## Eingaben (UI-Gruppen)

- Behälter- / Vakuum-Sollwerte (Betrieb).
- Gemeinsame Kapazitäten und hydraulische Leitung.
- Gasverarbeitungsfelder wenn aktiviert.

## Ausgaben / Entwurfstabellen

- Entwurfsdiagramme: pH, SI, Gaszusammensetzung vs Druck.
- Trockene und feuchte Gaszusammensetzung (v1.0.2+).
- Summen pro m³, pro Einheit und Prozess (v1.0.2+).
- Vakuumenergie.
