# Turmbelüftung

Bibliotheksname: **Turmbelüftung**. Gegenstrom-Füllkörperturm für CO₂-, CH₄-, O₂-Transfer und VOC-Strippung.

## Wann platzieren

Sie brauchen Füllkörper-Turm-Gastransfer (Entgasen von Methan/CO₂, Sauerstoffzugabe, VOC-Strippung).

## Ströme

- Ein/Aus: Produkt (kein Abfallstrom).

## Eingaben (UI-Gruppen)

- **Turm:** Durchmesser, Betthöhe, Füllkörper (Raflux25 / 50 / 90), Gebläsewirkungsgrad.
- **Hydraulische Leitung:** Düsendruckverlust, Fallhöhe.
- **Betrieb:** RQ, Umgebungstemperatur, min/nom/max wie geerbt.
- Die VOC-Liste kommt aus der stromaufwärtigen extraneous-Zusammensetzung.

## Ausgaben / Entwurfstabellen

- Entfernungsanteile und O₂-Zugabe auf dem Produktstrom.
- Entwurf: Flutungs- / Betriebskurven, Druckverlust, VOC-Kurven.
- Gebläseenergie (isentrope Verdichtung).
