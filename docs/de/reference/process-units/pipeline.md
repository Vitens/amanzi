# Transportleitung

Bibliotheksname: **Transportleitung**. Rohr für Druckverlust zwischen Einheiten. Keine benutzerdefinierte Qualitätsänderung.

## Wann platzieren

Sie brauchen Länge, Durchmesser und Rauheit zwischen zwei Punkten auf der hydraulischen Leitung.

## Ströme

- Ein/Aus: Produkt (oder welche Anker der Block freigibt).

## Eingaben (UI-Gruppen)

- **Transport:** Länge, Durchmesser, Material/Rauheit wie im Formular.
- Gemeinsame Höhen der hydraulischen Leitung.

## Ausgaben / Entwurfstabellen

- Druckverlust und Restdruckhöhe.
- Pumpenergie, wenn der Hydrauliksolver einen Booster impliziert.
