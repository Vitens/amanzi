# Kaskade

Bibliotheksname: **Kaskade**. Mehrstufige Kaskaden- (Treppen-) Belüftung.

## Wann platzieren

Sie modellieren Stufenbelüfter mit einer Anzahl von Fällen statt eines Füllkörperbetts.

## Ströme

- Ein/Aus: Produkt.

## Eingaben (UI-Gruppen)

- Anzahl Stufen, Stufenhöhe.
- Gemeinsame Kapazitäten und Belüftungs-Nachhaltigkeit.

## Ausgaben / Entwurfstabellen

- Annäherung an die Sättigung für O₂, CO₂, CH₄ (wie implementiert).
- Energie im Zusammenhang mit dem Pumpen zur Spitze der Kaskade.
