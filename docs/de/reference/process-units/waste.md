# Abfallstrom

Bibliotheksname: **Abfallstrom**. Senke für Konzentrat, verworfenes Wasser oder ungenutzte Spülung. Keine Gleichungen.

## Wann platzieren

Ein Abfall- oder ungenutzter Spülanker hat nirgendwo sonst hinzugehen.

## Ströme

- Ein: Abfall und/oder Spülung, je nachdem, was Sie verbinden.
- Kein Auslass.

## Eingaben (UI-Gruppen)

- Keine außer Blockname/Position.

## Ausgaben / Entwurfstabellen

- Durchfluss in der Menge verbucht (Verlust- / Abfallsummen).
- Keine Qualitätsumwandlung.
