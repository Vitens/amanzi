# Spritzbelüftung

Bibliotheksname: **Spritzbelüftung**. Tropfenfall für CO₂- und CH₄-Transfer.

## Wann platzieren

Sie wollen spritz-/kaskadenartigen Gastransfer ohne Füllkörper-Turm.

## Ströme

- Ein/Aus: Produkt.

## Eingaben (UI-Gruppen)

- Fallhöhe, RQ, Tropfen- / Sauter-Durchmesser wie freigegeben.
- Gemeinsame Nachhaltigkeitsfelder der Belüftung.

## Ausgaben / Entwurfstabellen

- Entfernungsanteile für die konfigurierten Gase.
- Empfindlichkeit im Entwurf vs Höhe und Tropfengröße.
