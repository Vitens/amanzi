# Membranfiltration

Bibliotheksname: **Membranfiltration**. Mehrstufiger RO/NF-Stack; Permeat ist Produkt, Konzentrat ist Abfall.

## Wann platzieren

Sie teilen den Strom in Permeat und Konzentrat mit einem Membranstack (Recovery, Stufung, Elementtyp).

## Ströme

- Ein: Produkt.
- Aus: Produkt (Permeat); Abfall (Konzentrat).

## Eingaben (UI-Gruppen)

- **Stack:** Membrantyp (ESPA2-LD, ESPA4, AK-400H, …), Anzahl Stufen (1–3), Module pro Behälter, Behälter, Recovery, Optiflux-Flag.
- **Hydraulische Leitung:** Patronenfilterverlust, Zwischenstufenverlust, Zulaufhöhe.
- Standardmäßig unter Druck.

## Ausgaben / Entwurfstabellen

- Tabelle auf Elementebene: Durchflüsse, Drücke, *Kw*.
- Stufendrücke und Recoveries.
- Energie der Hochdruckpumpen.
