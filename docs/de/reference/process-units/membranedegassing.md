# Membranentgassung

Bibliotheksname: **Membranentgassung**. Ein- oder zweistufiger Vakuum-Membrankontaktor.

## Wann platzieren

Sie strippen gelöste Gase durch einen Membrankontaktor unter Vakuum, nicht einen Füllkörper-Turm.

## Ströme

- Ein/Aus: Produkt.

## Eingaben (UI-Gruppen)

- **Entwurf / Betrieb:** RQ und Vakuum pro Stufe, Membrantyp, Anzahl Stufen.
- **Gasverarbeitung:** Entlüftungs- / Restgasoptionen aus der Gasverarbeitungsschicht.

## Ausgaben / Entwurfstabellen

- Gas–Flüssigkeits-Interaktion bei gesetztem Vakuum.
- Empirisches ΔP vs Last.
- Energie des Vakuumsystems; Nachhaltigkeit des Restgases (z. B. Methan).
