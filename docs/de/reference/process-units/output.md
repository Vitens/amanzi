# Lieferung

Bibliotheksname: **Lieferung**. Abgabepunkt / Senke für aufbereitetes Wasser. In jedem lösbaren Szenario erforderlich.

## Wann platzieren

Das Produktwasser verlässt die Anlage (Verteilungszulauf).

## Ströme

- Ein: Produkt.
- Kein weiteres stromabwärtiges Produkt.

## Eingaben (UI-Gruppen)

- Erforderlicher Abgabedruck / Druckhöhe.
- Optionaler integrierter Booster.
- Gemeinsame Höhe.

## Ausgaben / Entwurfstabellen

- Abgabedurchfluss (Menge).
- Booster-Energie wenn aktiviert.
- Qualität am Zapfhahn des Modells (Ende des PHREEQC-Laufs).
