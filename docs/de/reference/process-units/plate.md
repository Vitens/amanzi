# Plattenbelüftung

Bibliotheksname: **Plattenbelüftung**. Platten- / Kontaktbelüfter mit optionalem rezirkuliertem Abgas.

## Wann platzieren

Sie nutzen Plattenbelüfter statt eines Füllkörper-Turms oder einer Kaskade.

## Ströme

- Ein/Aus: Produkt.

## Eingaben (UI-Gruppen)

- **Entwurf:** Plattengeometrie wie im Formular.
- **Betrieb:** RQ, Rezirkulationsanteil.
- **Modell:** Effizienzfaktor.

## Ausgaben / Entwurfstabellen

- Gas–Flüssigkeits-Gleichgewicht nach Mehrfachdurchlauf-Luftinteraktion.
- Entwurfs-RQ-Sweep-Diagramme.
- Energie der Luftförderung.
