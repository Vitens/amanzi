# Teilen

Bibliotheksname: **Teilen**. Generische Durchflussaufteilung. Keine Qualitätsänderung.

## Wann platzieren

Sie teilen einen Strom zu zwei stromabwärtigen Einheiten ohne Aufbereitung.

## Ströme

- Ein Zulauf, zwei (oder mehr) Auslässe wie die Anker zeigen; Typen folgen den Verbindungen, die Sie zeichnen.

## Eingaben (UI-Gruppen)

- **Betrieb:** Aufteilungsanteil(e).

## Ausgaben / Entwurfstabellen

- Zweigdurchflüsse aus dem Mengensolver.
