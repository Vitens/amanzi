# Sandfang

Bibliotheksname: **Sandfang**. Hydraulische Dimensionierung eines Grit- / Sandfangs. **Keine Qualitätsumwandlung.**

## Wann platzieren

Sie brauchen ein hydraulisches Element für einen Sandfang in der Abfall- oder Rohwasserleitung.

## Ströme

- Ein/Aus: typischerweise auf einem Abfall- oder Rohwasserpfad (Bibliothekskategorie: Abfall).

## Eingaben (UI-Gruppen)

- Geometrie- und Geschwindigkeits- / Aufenthaltsfelder im Sandfang-Entwurfsabschnitt.
- Temperatur geht in die für die Dimensionierung genutzte Viskosität ein.

## Ausgaben / Entwurfstabellen

- Nur hydraulische Dimensionierungszahlen.
- Keine PHREEQC-Änderung.

## Wissenschaft

Keine erforderlich außer [Wie Amanzi berechnet](../../explanation/how-amanzi-calculates.md) (nur Menge/Hydraulik).
