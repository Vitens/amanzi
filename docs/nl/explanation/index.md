# Uitleg

Deze sectie is voor begrip. De **primer**-pagina’s zijn voor mensen die nieuw zijn in drinkwaterzuivering. De **wetenschaps**-pagina’s zijn voor key users die de modellen, aannames en literatuur willen.

Er is geen vaste leesvolgorde, maar een nuttige cyclus is: probeer een handleiding → doe een instructie → zoek een feit op → kom hier voor het waarom.

## Regels voor deze sectie

- Bespreken, vergelijken en citeren. Geen klik-voor-klik-stappen.
- Literatuur hoort hier, niet in handleidingen of instructies.
- Diagrammen: Mermaid-schetsen van processen en berekeningen.
