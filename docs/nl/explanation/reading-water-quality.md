# Waterkwaliteit lezen

Wat de kwaliteitslabels betekenen zonder chemiekennis. Voor de zijbalk van Amanzi, geen leerboek.

## Inhoud om te schrijven

- **pH** — hoe zuur/basisch; waarom installaties erom geven (corrosie, calciet, desinfectiecontext in één zin).
- **Hardheid / Ca / Mg** — “kalk” in water; waarom ontharding bestaat.
- **Fe, Mn** — vlekken en troebelheid; waarom zandfilters bestaan.
- **NH₄** — ammonium; vaak biologisch/chemisch verwijderd op filters.
- **CH₄ / H₂S / O₂ / N₂** — opgeloste gassen; waarom beluchting bestaat.
- **HCO₃, SI, CCPP/TACC₉₀** — calciet / agressiviteit, elk in één toegankelijke alinea.
- **EGV / sc20 / TDS** — hoe “zout” of geleidend het water is.
- **PFAS** — persistente door de mens gemaakte stoffen, ng/L, gegroepeerd als Sum4/Sum20/PEQ; details in [Aktiefkool en PFAS](activated-carbon-and-pfas.md).
- Deze getallen komen uit **PHREEQC** vanaf de analyse die je op Winning hebt ingetypt — je hoeft PHREEQC niet zelf te draaien.
