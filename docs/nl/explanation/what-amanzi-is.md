# Wat Amanzi is

Amanzi is voor het **ontwerpen en vergelijken van behandelingsscenario’s**, niet voor het draaien van een live installatie.

## Inhoud om te schrijven

- Wie het heeft gebouwd (Vitens) en waarom scenariowerk lastig is zonder een gedeelde tekening + berekening.
- Wat je krijgt: een stroomschema, meerdere what-ifs, getallen voor hoeveelheid, kwaliteit, energie, chemicaliën, CO₂.
- Wat het **niet** is: SCADA, een laboratorium, een juridisch bindend ontwerp, een tijdreeks-digital twin.
- Browserengine (Pyodide) vs gehoste demo: hetzelfde idee, geen server op je bureau.
- GPL-3.0 en het citeren van de software (About-dialoog) — één alinea, link naar de licentie.
- Hoe dit samenhangt met de vier documentatietypen (herhaal de handleidingen niet).
