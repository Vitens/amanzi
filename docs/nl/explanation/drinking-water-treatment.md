# Drinkwaterzuivering

Grondwater wordt drinkwater via een reeks stappen. Alledaagse taal; geen plantontwerpcursus.

## Inhoud om te schrijven

- Grondwater bevat al opgeloste stoffen (ijzer, hardheid, methaan, soms PFAS).
- Een **behandelingstrein** is een volgorde van ruimtes/machines, elk met één taak (beluchten, filtreren, ontharden, doseren, membraan, kool).
- **Productwater** gaat richting de kraan; **afval** is concentraat of slibwater dat niet als drinkwater mag; **spoeling** is waswater van filters.
- Waarom een tekening van vakken en pijlen een nuttig model van die trein is.
- De bibliotheek van Amanzi is die set vakken voor een typische Nederlandse grondwaterwinning — niet elk proces op aarde.

## Diagrammen

- Mermaid: grondwater → beluchting/filtratie/ontharding/… → drinkwater, met afval-/spoelzijstromen.
