# Membraanfiltratie

Bibliotheeknaam: **Membraanfiltratie**. Meertraps RO/NF-stack; permeaat is product, concentraat is afval.

## Wanneer plaatsen

Je splitst de stroom in permeaat en concentraat met een membraanstack (recovery, staging, elementtype).

## Stromen

- In: productstroom.
- Uit: productstroom (permeaat); afvalstroom (concentraat).

## Invoer (UI-groepen)

- **Stack:** membraantype (ESPA2-LD, ESPA4, AK-400H, …), aantal trappen (1–3), modules per vessel, vessels, recovery, optiflux-vlag.
- **Hydraulische lijn:** cartridgefilterverlies, interstage-verlies, inlaathoogte.
- Standaard onder druk.

## Uitvoer / ontwerptabellen

- Elementtabel: debieten, drukken, *Kw*.
- Stagedrukken en recoveries.
- Energie van hogedrukpompen.
