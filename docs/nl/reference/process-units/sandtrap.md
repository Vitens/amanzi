# Zandvang

Bibliotheeknaam: **Zandvang**. Hydraulische dimensionering van een grit- / zandvang. **Geen kwaliteitstransformatie.**

## Wanneer plaatsen

Je hebt een hydraulisch element nodig voor een zandvang in de afval- of ruwwaterleiding.

## Stromen

- In/uit: typisch op een afval- of ruwwaterpad (bibliotheekcategorie: afval).

## Invoer (UI-groepen)

- Geometrie- en snelheids- / verblijftijdvelden in de zandvang-ontwerpsectie.
- Temperatuur gaat in de viscositeit die voor dimensionering wordt gebruikt.

## Uitvoer / ontwerptabellen

- Alleen hydraulische dimensioneringsgetallen.
- Geen PHREEQC-wijziging.
