# Torenbeluchting

Bibliotheeknaam: **Torenbeluchting**. Tegenstroom gepakte toren voor CO₂-, CH₄-, O₂-overdracht en VOC-stripping.

## Wanneer plaatsen

Je hebt gasoverdracht in een gepakte toren nodig (ontgassen methaan/CO₂, zuurstof toevoegen, VOC strippen).

## Stromen

- In/uit: productstroom (geen afvalstroom).

## Invoer (UI-groepen)

- **Toren:** diameter, bedhoogte, pakking (Raflux25 / 50 / 90), blowerrendement.
- **Hydraulische lijn:** drukverlies sproeikop, valhoogte.
- **Operationeel:** RQ, omgevingstemperatuur, min/nom/max zoals geërfd.
- VOC-lijst komt uit upstream extraneous-samenstelling.

## Uitvoer / ontwerptabellen

- Verwijderingsfracties en O₂-toevoeging op de productstroom.
- Ontwerp: flooding-/bedrijfsgrafieken, drukval, VOC-curven.
- Blowerenergie (isentropische compressie).
