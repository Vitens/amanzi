# Sproeibeluchting

Bibliotheeknaam: **Sproeibeluchting**. Druppelval voor CO₂- en CH₄-overdracht.

## Wanneer plaatsen

Je wilt sproei-/cascade-achtige gasoverdracht zonder gepakte toren.

## Stromen

- In/uit: productstroom.

## Invoer (UI-groepen)

- Valhoogte, RQ, druppel- / Sauter-diameter zoals getoond.
- Gedeelde beluchting-sustainabilityvelden.

## Uitvoer / ontwerptabellen

- Verwijderingsfracties voor de geconfigureerde gassen.
- Ontwerpgevoeligheid vs hoogte en druppelgrootte.
