# Levering

Bibliotheeknaam: **Levering**. Afleverpunt / sink voor behandeld water. Vereist in elk oplosbaar scenario.

## Wanneer plaatsen

Het productwater de installatie verlaat (ingang distributie).

## Stromen

- In: productstroom.
- Geen verdere downstream-productstroom.

## Invoer (UI-groepen)

- Vereiste afleverdruk / -drukhoogte.
- Optionele geïntegreerde booster.
- Gedeelde hoogte.

## Uitvoer / ontwerptabellen

- Afleverdebiet (hoeveelheid).
- Boosterenergie indien ingeschakeld.
- Kwaliteit aan de kraan van het model (einde van de PHREEQC-wandeling).
