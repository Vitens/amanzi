# Cascade

Bibliotheeknaam: **Cascade**. Meertraps cascade- (trap-)beluchting.

## Wanneer plaatsen

Je modelleert trapbeluchters met een aantal vallen in plaats van een gepakt bed.

## Stromen

- In/uit: productstroom.

## Invoer (UI-groepen)

- Aantal treden, tredehoogte.
- Gedeelde capaciteiten en beluchting-sustainability.

## Uitvoer / ontwerptabellen

- Benadering van verzadiging voor O₂, CO₂, CH₄ (zoals geïmplementeerd).
- Energie gekoppeld aan pompen naar de top van de cascade.
