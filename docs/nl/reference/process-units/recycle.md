# Spoelwaterhergebruik

Bibliotheeknaam: **Spoelwaterhergebruik**. Recycle / splitsing die een lus stroomopwaarts kan sluiten.

## Wanneer plaatsen

Je stuurt spoeling of een zijstroom terug naar een eerdere unit.

## Stromen

- Splitsing-stijl: inkomend debiet gesplitst naar product/recycle volgens het blok.
- Kwaliteit wordt doorgestuurd (geen behandeling).

## Invoer (UI-groepen)

- Splitsfracties / recycle-ontwerpvelden zoals in het formulier.

## Uitvoer / ontwerptabellen

- Debieten op elke tak.
- Energie als pompen is inbegrepen.
- Let op: recycle-massahulp retourneert leeg om de hoeveelheidssolver te laten convergeren (feit voor key users die deze pagina vullen).
