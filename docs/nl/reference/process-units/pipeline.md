# Transportleiding

Bibliotheeknaam: **Transportleiding**. Leiding voor headloss tussen units. Geen eigen kwaliteitswijziging.

## Wanneer plaatsen

Je hebt lengte, diameter en ruwheid nodig tussen twee punten op de hydraulische lijn.

## Stromen

- In/uit: productstroom (of welke ankers het blok toont).

## Invoer (UI-groepen)

- **Transport:** lengte, diameter, materiaal/ruwheid zoals in het formulier.
- Gedeelde hydraulische-lijnhhoogtes.

## Uitvoer / ontwerptabellen

- Headloss en restdrukhoogte.
- Pompenergie als een booster door de hydraulische solver wordt geïmpliceerd.
