# Afvalstroom

Bibliotheeknaam: **Afvalstroom**. Sink voor concentraat, afgevoerd water of ongebruikte spoeling. Geen vergelijkingen.

## Wanneer plaatsen

Een afval- of ongebruikte-spoelanker nergens anders naartoe kan.

## Stromen

- In: afvalstroom en/of spoeling, afhankelijk van wat je verbindt.
- Geen uitlaat.

## Invoer (UI-groepen)

- Geen buiten bloknaam/positie.

## Uitvoer / ontwerptabellen

- Debiet meegenomen in hoeveelheid (verlies- / afvaltotalen).
- Geen kwaliteitstransformatie.
