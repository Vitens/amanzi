# Membraanontgassing

Bibliotheeknaam: **Membraanontgassing**. Een- of tweetraps vacuum-membraancontactor.

## Wanneer plaatsen

Je stript opgeloste gassen via een membraancontactor onder vacuum, niet via een gepakte toren.

## Stromen

- In/uit: productstroom.

## Invoer (UI-groepen)

- **Ontwerp / operationeel:** RQ en vacuum per trap, membraantype, aantal trappen.
- **Gasverwerking:** vent- / restgasopties uit de gasverwerkingslaag.

## Uitvoer / ontwerptabellen

- Gas–vloeistofinteractie bij ingesteld vacuum.
- Empirische ΔP vs belasting.
- Energie van vacuumsysteem; sustainability van restgas (bijv. methaan).
