# Plaatbeluchting

Bibliotheeknaam: **Plaatbeluchting**. Plaat- / contactbeluchter met optioneel gerecirculeerd afgas.

## Wanneer plaatsen

Je gebruikt plaatbeluchters in plaats van een gepakte toren of cascade.

## Stromen

- In/uit: productstroom.

## Invoer (UI-groepen)

- **Ontwerp:** plaatreometrie zoals in het formulier.
- **Operationeel:** RQ, recirculatiefractie.
- **Model:** efficiëntiefactor.

## Uitvoer / ontwerptabellen

- Gas–vloeistofevenwicht na meervoudige luchtinteractie.
- Ontwerp-RQ-sweepgrafieken.
- Energie van luchtafhandeling.
