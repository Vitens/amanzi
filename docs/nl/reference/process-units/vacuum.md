# Vacuumontgassing

Bibliotheeknaam: **Vacuumontgassing**. Eentraps vacuumstripper (geen membraancontactor).

## Wanneer plaatsen

Je ontgast door de gasfasedruk op een vat te verlagen, en wilt pH / SI / gassamenstelling vs vacuum.

## Stromen

- In/uit: productstroom.

## Invoer (UI-groepen)

- Vat- / vacuumsetpoints (operationeel).
- Gedeelde capaciteiten en hydraulische lijn.
- Gasverwerkingsvelden indien ingeschakeld.

## Uitvoer / ontwerptabellen

- Ontwerpgrafieken: pH, SI, gassamenstelling vs druk.
- Droge en natte gassamenstelling (v1.0.2+).
- Totalen per m³, per unit en proces (v1.0.2+).
- Vacuumenergie.
