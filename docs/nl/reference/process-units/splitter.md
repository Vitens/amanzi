# Splitsing

Bibliotheeknaam: **Splitsing**. Generieke debietssplitsing. Geen kwaliteitswijziging.

## Wanneer plaatsen

Je verdeelt een stroom naar twee downstream-units zonder behandeling.

## Stromen

- Eén inlaat, twee (of meer) uitlaten zoals de ankers tonen; typen volgen de verbindingen die je trekt.

## Invoer (UI-groepen)

- **Operationeel:** splitsfractie(s).

## Uitvoer / ontwerptabellen

- Takdebieten uit de hoeveelheidssolver.
