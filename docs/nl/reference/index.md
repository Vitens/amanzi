# Naslag

Feiten over de interface, stromen, resultaatfamilies, eenheden en procesblokken. Als je *waarom* nodig hebt, ga naar [Uitleg](../explanation/index.md). Als je *stappen* nodig hebt, ga naar [Instructies](../how-to/index.md).

## Regels voor deze sectie

- Vermeld wat iets is, wat het accepteert, wat het toont.
- Geen klik-voor-klik-procedures en geen literatuur.
- Parametergroepen komen uit de parametrische definitie van de unit; vul tabellen later vanuit YAML, verzin hier geen bereiken.
