# Begrippenlijst

Korte definities. Geen essays.

## Inhoud om te schrijven

- **Scenario** — één versie van de installatie binnen een project.
- **Project** — JSON-bestand met een of meer scenario’s.
- **Stroomschema / canvas** — de tekening van units en stromen.
- **Kengetal** — gedeelde opzoekwaarde (emissiefactor, limiet, rendement).
- **Winning** — grondwaterbronblok.
- **Productstroom / afvalstroom / spoeling** — de drie stroomtypen.
- **Spoeling** — wassen van een filterbed; vaak een spoelstroom.
- **EBCT** — empty bed contact time (GAC).
- **BV** — bed volumes.
- **GAC** — granular activated carbon.
- **RQ** — lucht-waterratio (beluchting).
- **SI** — saturatie-index (calciet tenzij anders vermeld).
- **CCPP / TACC₉₀** — calcium carbonate precipitation potential / gerelateerd UI-label.
- **PHREEQC** — de chemie-engine die Amanzi gebruikt.
- **PFAS** — per- and polyfluoroalkyl substances.
- **Sum4 / Sum20 / PEQ** — gegroepeerde PFAS-metrieken (limieten uit kengetallen).
- **VOC** — vluchtige organische stoffen (extraneous-lijst).
- **RO / NF** — reverse osmosis / nanofiltration.
- **Kw** — membraanwaterpermeabiliteit.
- **HTU / NTU** — hoogte / aantal transfer units (gepakte toren).
- **Freundlich K, 1/n** — isothermparameters; 1/n is de exponent.
- **SRS** — Sheindorf–Rebhun–Sheintuch competitieve Freundlich.
- **Pelletontharding** — calciet-pelletreactor (UI kan Pelletontharding zeggen).
