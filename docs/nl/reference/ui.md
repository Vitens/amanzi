# Gebruikersinterface

Benoemde onderdelen van het Amanzi-venster.

## Inhoud om te schrijven

- **Bovenbalk:** projectnaam, hernoemen, downloaden/uploaden/opslaan/resetten, Project berekenen, zoom fit, kengetallen, taal, tutorial, about, feedback.
- **Bibliotheek (links):** groepen Hoofdstroom vs Afvalstroom; filter/zoeken; raster vs lijst indien aanwezig.
- **Canvas:** pannen, zoomen, raster; blokposities zijn alleen lay-out (geen geografie).
- **Resultatenbalk (rechts):** tabs hoeveelheid, kwaliteit, energie, sustainability; tab Kengetallen.
- **Scenariotabs (onderaan):** toevoegen, hernoemen, verwijderen, notities.
- **Unitdialogen:** configuratieformulier, ontwerpgrafieken/-tabellen, hydraulische lijn.
- **Rapportdialoog:** enkel- en meerscenario.
- **About:** licentie (GPL-3.0), dankbetuigingen (PHREEQC, PhreeqPython, Vue, Element Plus), citatie.
- **Init-dialoog:** voortgang laden van de engine.
