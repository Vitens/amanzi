# Opslaan, laden, downloaden

Bewaar een project in de browser, download het als JSON, of vervang het huidige project door een bestand te uploaden.

## Inhoud om te schrijven

- Menuacties: opslaan / downloaden / uploaden / resetten (labels uit het Project-menu).
- Browseropslag vs gedownload `.json`: opslag is handig; het bestand is de kopie die je kunt delen.
- Uploaden **vervangt** het open project; waarschuw voor het overschrijven van niet-opgeslagen wijzigingen als de UI dat doet.
- Versiemigratie-toast: bestandsformaat opgewaardeerd; wat je de gebruiker vertelt (veilig om door te gaan; noteer het versiebereik).
- Hernoem het project vanuit de bovenbalk zodat de gedownloade bestandsnaam overeenkomt.
