# Kengetallen instellen

Stel projectbrede (en optionele scenario-)getallen in die veel berekeningen delen: emissiefactoren, PFAS-limieten en vergelijkbare opzoekwaarden.

## Inhoud om te schrijven

- Open de tab **Kengetallen** in de rechterzijbalk (en de kengetallendialoog vanuit de bovenbalk).
- Projectoverschrijvingen vs scenario-overschrijvingen: wanneer een scenario moet afwijken.
- Wanneer een waarde aanpassen: CO₂-aannames vergelijken, of een wettelijke Sum4/Sum20/PEQ-limiet matchen — niet voor het dagelijks tekenen van het stroomschema.
- Zoeken/filteren in de kengetallenlijst.
- De ingebouwde databasewaarde voor één rij herstellen.
- Feiten over de database zelf: [Kengetallen](../reference/key-figures.md).
