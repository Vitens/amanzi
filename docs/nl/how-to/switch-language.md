# Taal wisselen

Zet de gebruikersinterface op Engels, Nederlands, Duits of Frans.

## Inhoud om te schrijven

- Waar de locale-bediening zit (en dat de standaard de browsertaal volgt).
- De vier locales: `en`, `nl`, `de`, `fr`.
- Wat wisselt: bibliotheeknamen, formulierlabels, tutorialtekst, about-dialoog.
- Deze documentatiesite heeft dezelfde vier talen (Engels, Nederlands, Duits, Frans) via een eigen taalkiezer. Het is een aparte kopie van de pagina’s, niet de JSON-catalogus van de app.
- Wat **niet** wisselt: project-JSON-veldnamen, kengetalsleutels. Architectuurdocumentatie blijft Engels.
- Sommige unitnamen blijven gemengd (voorbeeld: pelletontharding kan als “Pelletontharding” verschijnen).
