# Sla je werk op

Je werk is een **projectbestand**, geen account. Download het als je het morgen of op een andere computer wilt.

## Inhoud om te schrijven

- De browser bewaart lokaal een kopie zolang de tab in gebruik is; dat is geen back-up.
- **Downloaden** schrijft een `.json`-bestand met de projectnaam.
- **Uploaden** vervangt wat op het scherm staat door dat bestand.
- Je kunt het bestand mailen; een collega opent het op dezelfde manier in Amanzi.
- Als Amanzi zegt dat het bestand is bijgewerkt naar een nieuwere versie, is dat normaal wanneer versies verschillen — details in [Opslaan, laden, downloaden](../how-to/save-load-download.md).
