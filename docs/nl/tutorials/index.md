# Handleidingen

Deze sectie leert door te doen. Werk in het **demoproject** dat Amanzi voor je opent. Begin niet vanaf een leeg canvas en verzin geen grondwateranalyse.

De in-app-tutorial (Help → Tutorial) is een optionele extra met korte video’s van dezelfde eerste stappen. Deze pagina’s geven namen aan wat je ziet en wat je daarna kunt proberen.

## Regels voor deze sectie

- Eén happy path per pagina; geen zijpaden.
- Alleen demodata.
- Geen literatuur, geen parameterdumps, geen chemielessen.
- Diagrammen: Mermaid-wireframes van het scherm, geen screenshots.

## Pagina’s

- [Open Amanzi](open-amanzi.md) — start de app en benoem de hoofdonderdelen van het scherm.
- [Je eerste installatie](first-plant.md) — loop het demostroomschema door en bekijk de resultaten.
- [Verander één ding](change-one-thing.md) — pas een parameter aan en zie getallen bewegen.
- [Scenario’s vergelijken](compare-scenarios.md) — een tweede what-if en het rapport.
- [Sla je werk op](save-your-work.md) — je project is een bestand, geen account.

## Inhoud om te schrijven

- Hoe je deze sectie gebruikt (eerst demo; in-app-tutorial als optionele extra).
- Voorgestelde volgorde van de vijf handleidingen.
- Wat je hier *niet* moet verwachten (theorie staat in Uitleg; parameterlijsten in Naslag).
