# Scenario’s vergelijken

Een scenario is één versie van de installatie. Maak een tweede versie, verander één ontwerpkeuze, en open het rapport.

## Inhoud om te schrijven

- Scenariotabs zitten onderaan; `+` maakt een nieuw scenario.
- Kopieer het demo-idee: houd dezelfde lay-out, verander één blok of één getal zodat de twee tabs vergelijkbaar zijn.
- Notities bij een scenario (v1.0.5) zijn voor jezelf; ze veranderen de berekening niet.
- **Project berekenen** / rapport: bekijk de vergelijking van hoeveelheid, kwaliteit, energie en sustainability over de tabs.
- Leg hier niet uit hoe CO₂ wordt berekend — dat staat in [Hoeveelheid, energie, chemicaliën, CO₂](../explanation/quantity-energy-chemicals-co2.md).
