# Change one thing

Edit one obvious parameter on one unit, watch the sidebar numbers move, then undo.

## Content to write

- Double-click a treatment block (or use Edit) to open configuration.
- Change one labelled field the demo already filled in (capacity or a simple efficiency) — not Freundlich coefficients or ion lists.
- Watch the right sidebar and any open design graphs update; Amanzi recalculates after a short pause.
- Use undo to put the demo back.
- Point to [Configure a unit](../how-to/configure-a-unit.md) for other fields, and to [Reading water quality](../explanation/reading-water-quality.md) if a quality name is confusing.
