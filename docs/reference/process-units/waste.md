# Waste stream

Library name: **Waste stream**. Sink for concentrate, discarded water, or unused flush. No equations.

## Place it when

A waste or unused flush anchor has nowhere else to go.

## Streams

- In: waste and/or flush, depending on what you connect.
- No outlet.

## Inputs (UI groups)

- None beyond the block name/position.

## Outputs / design tables

- Flow accounted in quantity (loss / waste totals).
- No quality transformation.
