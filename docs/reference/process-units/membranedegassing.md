# Membrane degassing

Library name: **Membrane degassing**. One- or two-stage vacuum membrane contactor.

## Place it when

You strip dissolved gases through a membrane contactor under vacuum, not a packed tower.

## Streams

- In/out: product.

## Inputs (UI groups)

- **Design / operational:** RQ and vacuum per stage, membrane type, number of stages.
- **Gas processing:** vent / residual gas options from the gas-processing layer.

## Outputs / design tables

- Gas–liquid interaction at set vacuum.
- Empirical ΔP vs load.
- Energy of vacuum system; sustainability of residual gas (e.g. methane).
