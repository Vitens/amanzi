# Tutoriels

Suivez ces pages dans l'ordre. Restez dans le projet de démonstration qu'Amanzi ouvre. Laissez le canevas tel que vous le trouvez, jusqu'à ce qu'une page plus loin vous demande de modifier une chose.

**Aide → Tutoriel** dans l'application est une visite courte et facultative des mêmes premiers pas. Ces pages nomment les parties de l'écran et indiquent quoi essayer ensuite.

1. [Ouvrir Amanzi](open-amanzi.md) — démarrez l'application et nommez les zones principales de l'écran.
2. [Votre première installation](first-plant.md) — suivez le schéma de la démo et jetez un œil aux résultats.
3. [Modifier un paramètre](change-one-thing.md) — modifiez un paramètre et regardez les chiffres bouger.
4. [Comparer des scénarios](compare-scenarios.md) — faites une deuxième version et ouvrez le rapport.
5. [Enregistrer votre travail](save-your-work.md) — conservez le projet dans un fichier.

Le comportement des éléments est dans les Explications. Les listes de paramètres et d'unités sont dans la Référence.
