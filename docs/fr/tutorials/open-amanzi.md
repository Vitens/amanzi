# Ouvrir Amanzi

Ouvrez l'application et apprenez les noms des zones de l'écran. Laissez l'installation telle que vous la trouvez.

## Ouvrir l'application

Ouvrez [https://demo.amanzi.app](https://demo.amanzi.app).

La première fois, une fenêtre intitulée **Démarrage d'AMANZI...** reste affichée pendant le chargement du programme de calcul. Elle se ferme toute seule.

Pour décompresser une version et servir cette copie, suivez [Ouvrir en ligne ou en local](../how-to/open-hosted-or-local.md).

## Fermer le tutoriel

Une fenêtre intitulée **Tutoriel** peut alors recouvrir le projet. Parcourez-la pour voir les fonctions de base et la façon d'utiliser Amanzi.
Toutes ces informations se trouvent aussi dans ce parcours.
Si vous savez déjà comment Amanzi fonctionne, cochez la case en bas à gauche avant de fermer le tutoriel, pour qu'il ne se rouvre pas à votre prochaine visite.

**Aide → Tutoriel** rouvre la visite quand vous le souhaitez.

## L'écran

Amanzi est divisé en trois zones principales. Les outils de scénario à gauche, le canevas au milieu et l'aperçu des résultats à droite.

Les outils de scénario comprennent :
- un champ de notes, pour consigner des remarques ou des hypothèses du scénario en cours
- la bibliothèque de modèles, qui contient tous les modèles de traitement de l'eau et de flux de rejet utilisables pour construire la filière
- le champ de configuration, affiché quand vous sélectionnez un modèle : vous y changez rapidement un paramètre, ou vous ouvrez la vue conception

Le canevas est l'espace d'essai où vous placez les blocs de modèles et les reliez en une filière de traitement pour votre cas. Vous pouvez glisser-déposer les modèles sur le canevas et les faire se connecter tout seuls. Voir [Ajouter et relier des unités](../how-to/add-and-connect-units.md).

Dans l'aperçu des résultats, Amanzi affiche des résultats pour **Qualité**, **Quantité**, **Énergie** et **Durabilité**.
Pour la qualité, chaque composé a un code couleur qui indique s'il respecte ou non les normes de l'eau potable.

La barre du haut contient la navigation, le réglage de la langue et d'autres fonctions.
