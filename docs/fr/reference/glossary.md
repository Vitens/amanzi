# Glossaire

**Captage.** Le bloc source d'eau souterraine. Nom dans la bibliothèque : **Captage**.

**AggCO₂.** Dioxyde de carbone agressif, le CO₂ qui peut encore dissoudre la calcite.

**Lavage.** Eau de lavage qui nettoie un lit filtrant. Sur le canevas, c'est un flux de lavage.

**Canevas.** Le dessin des unités et des flux. Appelé aussi schéma de procédé.

**CCPP, TACC₉₀.** Potentiel de précipitation du carbonate de calcium. Le libellé du panneau est **TACC₉₀**. La cible de dosage est `CCPP90`.

**EGV.** Conductivité électrique, mS/m. La balise d'indicateur de la limite associée est `sc20`.

**Flux de lavage.** Le flux pointillé. Lavage et autres eaux de lavage.

**HTU, NTU.** Hauteur d'une unité de transfert, et leur nombre. La tour à garnissage utilise les deux.

**Indicateur.** Une valeur de consultation partagée : un rendement, un facteur d'émission ou une limite de qualité. La balise, la valeur par défaut et l'unité figurent dans la liste des indicateurs.

**Kw.** Perméabilité à l'eau d'un élément membranaire, m³/(m²·bar·h), issue de la ligne d'essai du fabricant et d'une correction de température.

**NF.** Nanofiltration. Dans cette application, c'est un type d'élément d'empilement membranaire, pas un bloc distinct.

**Distribution.** L'exutoire du flux produit. Nom dans la bibliothèque : **Distribution**. Le bloc de la démo est souvent nommé **Distribution**.

**Adoucissement sur pellets.** Le réacteur à pellets de calcite. Le nom dans la bibliothèque est **Adoucissement sur pellets**.

**PHREEQC.** Le moteur chimique. Amanzi l'appelle via PhreeqPython dans le navigateur.

**Produit.** Le flux bleu. Eau qui continue vers la distribution.

**Projet.** Le fichier d'un ou de plusieurs scénarios, plus les redéfinitions d'indicateurs du projet. JSON sur disque. Une copie dans le navigateur également, après Enregistrer.

**RQ.** Rapport air-eau sur un aérateur. Sans dimension.

**RO.** Osmose inverse. Le bloc de filtration membranaire.

**Scénario.** Une version de l'usine à l'intérieur d'un projet. Un point de fonctionnement stationnaire.

**SI.** Indice de saturation de la calcite, sauf si une unité indique autre chose.

**TAC.** Alcalinité telle qu'affichée sur le panneau de qualité.

**TH.** Dureté telle qu'indiquée sur le dessin d'adoucissement sur pellets. Le panneau de l'usine appelle le résultat de l'usine **Dureté**.

**Rejet.** Le flux rouge. Eau qui n'est pas livrée comme eau potable.
