# Flux de rejet

Nom dans la bibliothèque : **Flux de rejet**. L’exutoire d’une ligne rouge. La démo le nomme **Flux de rejet**.

## Quand le placer

Un filtre, une membrane ou un autre bloc a une sortie de rejet qui doit être raccordée. Un ancrage de rejet obligatoire laissé ouvert empêche le scénario d’être entièrement connecté.

## Flux

Entrée : rejet. Rien ne sort. Le débit qui arrive ici fait partie de la perte de quantité, sauf si un bloc de [réutilisation des eaux de lavage](recycle.md) en a déjà renvoyé une partie vers le produit.
