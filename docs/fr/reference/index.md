# Référence

Ce catalogue indique ce que contient l'application publique : la fenêtre, les trois flux, les panneaux de résultats, les indicateurs, les unités de mesure et chaque bloc de la bibliothèque. La raison pour laquelle un nombre varie est dans [Explications](../explanation/index.md). La façon de modifier quelque chose est dans les [guides pratiques](../how-to/index.md). Un premier parcours de la démo est dans les [tutoriels](../tutorials/index.md).

Les tableaux de paramètres sont les entrées enregistrées pour chaque bloc. Les valeurs par défaut et les plages sont les valeurs dans `amanzi/parametric/`. Un champ marqué comme une fraction est enregistré de 0 à 1 même lorsque son libellé indique %.
