# Explications

Ces pages servent à comprendre. Elles exposent le fonctionnement d'une filière de traitement et la façon dont Amanzi la calcule. Les étapes pour accomplir une tâche se trouvent dans les [guides pratiques](../how-to/index.md). Une première traversée de la démo se trouve dans les [tutoriels](../tutorials/index.md). Les noms, les champs et les valeurs permises se trouvent dans la [référence](../reference/index.md). Ce découpage suit la carte [Diátaxis](https://diataxis.fr/map/) : tutoriel, guide pratique, référence, explication.

Il n'y a pas d'ordre imposé. Un cycle utile consiste à essayer un tutoriel, à suivre un guide pratique, à consulter un champ, puis à venir ici pour comprendre pourquoi le nombre a bougé.
