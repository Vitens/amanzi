# Configurer une unité

Vous réglez une sélection de paramètres de conception d'un bloc de traitement en sélectionnant ce bloc. Les paramètres s'affichent dans un cadre en bas à gauche. Vous pouvez les modifier directement.

Pour un réglage plus complet, double-cliquez sur le bloc de traitement à modifier.
Cela ouvre une vue conception du modèle de traitement, avec une visualisation des concentrations d'entrée et de sortie, et les paramètres de conception dans le cadre de gauche. Pour aider à choisir les bons paramètres, beaucoup de modèles incluent des graphiques qui montrent comment un changement de paramètre modifie le comportement du traitement.




## Contenu à rédiger

- Ouvrir : double-cliquez sur le bloc, ou utilisez la commande de modification des paramètres.
- Catégories du formulaire (conception, exploitation, réactifs, ligne hydraulique — telles que l'interface les nomme).
- Les changements s'appliquent après une courte pause ; les graphiques et tableaux de conception dans la fenêtre se mettent à jour en même temps que le panneau de toute l'installation.
- Rétablir la valeur par défaut pour cette unité.
- Les champs conditionnels (exemple : dimensions de filtre circulaire ou rectangulaire) n'apparaissent que quand le choix parent correspond.
- Où chercher les plages autorisées : [unités de procédé](../reference/process-units/index.md), pas cette page.
