# Copier entre scénarios

Vous pouvez copier un ou plusieurs blocs de modèles avec le classique `Ctrl+C`, puis les coller sur le canevas du même scénario ou dans un autre scénario avec `Ctrl+V`.
Copier-coller plusieurs blocs conserve aussi les liaisons entre eux.

Vous dupliquez le scénario en cours depuis le menu déroulant en haut,

ou depuis le menu de scénario en bas du canevas.




## Contenu à rédiger

- Sélectionnez un ou plusieurs blocs ; `Ctrl+C` / `Ctrl+V` (pareil sur macOS, avec la touche habituelle).
- Dupliquer sur le même canevas, ou coller dans un autre onglet de scénario.
- Liaisons : ce qui est copié avec le bloc, et ce que vous devez rebrancher.
- Notes de scénario (v1.0.5) : les ajouter, les modifier ; elles n'agissent pas sur les solveurs.
- Renommer ou supprimer un onglet de scénario ; vous ne pouvez pas laisser le projet sans aucun scénario si l'interface l'interdit — documentez la règle réelle.
