# Scenarios and flowsheets

The canvas is a **mass-balance model**. Tabs are **what-if versions**, not different days of the week.

## Content to write

- A flowsheet says: this much water of this quality enters here, these units change it, this much leaves as product or waste.
- Steady state: one operating point (min/nom/max capacities), not a 24-hour animation.
- Positions on the canvas are for humans; hydraulics use elevations and losses you type, not the drawing scale.
- Multiple scenarios = compare designs (extra GAC vs extra aeration), not “Monday vs Tuesday”.
- The JSON project file *is* the model; the UI is the editor.
