# What Amanzi is

Amanzi is for **designing and comparing treatment scenarios**, not for running a live plant.

## Content to write

- Who built it (Vitens) and why scenario work is hard without a shared drawing + calculation.
- What you get: a flowsheet, several what-ifs, numbers for quantity, quality, energy, chemicals, CO₂.
- What it is **not:** SCADA, a laboratory, a legally binding design, a time-series digital twin.
- Browser engine (Pyodide) vs hosted demo: same idea, no server on your desk.
- GPL-3.0 and citing the software (About dialog) — one paragraph, link to license.
- How this relates to the four documentation types (do not repeat the tutorials).
