# Save your work

Your work is a **project file**, not an account. Download it if you want it tomorrow or on another computer.

## Content to write

- The browser keeps a copy locally while the tab is in use; that is not a backup.
- **Download** writes a `.json` file named after the project.
- **Upload** replaces what is on screen with that file.
- You can email the file; a colleague opens it in Amanzi the same way.
- If Amanzi says the file was updated to a newer version, that is expected when versions differ — details in [Save, load, download](../how-to/save-load-download.md).

## Diagrams

- Mermaid: canvas ⇄ `.json` file ⇄ another computer / email.
