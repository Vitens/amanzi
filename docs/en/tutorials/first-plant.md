# Your first plant

Walk the demo project: water comes from a source, passes treatment blocks, and leaves at an outlet. Glance at the result bar. No chemistry lecture.

## Content to write

- Every scenario needs a **source** (abstraction) and a **sink** (output). The demo already has both.
- Follow the **product** path (blue) from left to right; mention **waste** (red) and **flush / backwash** (dotted) only as “other pipes you will see”.
- Click one block so the right sidebar shows numbers; do not edit yet.
- Result families to notice, in one sentence each: quantity (how much water), quality (what is in it), energy, chemicals, sustainability (CO₂).
- If the canvas looks red or “not fully connected”, that is a wiring problem — save the fix for the how-to.
