# User interface

Named parts of the Amanzi window.

## Content to write

- **Top bar:** project name, rename, download/upload/save/reset, Calculate project, zoom fit, key figures, language, tutorial, about, feedback.
- **Library (left):** Main stream vs Waste stream groups; filter/search; grid vs list if present.
- **Canvas:** pan, zoom, grid; block positions are layout only (not geography).
- **Result sidebar (right):** quantity, quality, energy, sustainability tabs; Key figures tab.
- **Scenario tabs (bottom):** add, rename, delete, notes.
- **Unit dialogs:** configuration form, design graphs/tables, hydraulic line.
- **Report dialog:** single- and multi-scenario.
- **About:** license (GPL-3.0), acknowledgements (PHREEQC, PhreeqPython, Vue, Element Plus), citation.
- **Init dialog:** engine loading progress.
