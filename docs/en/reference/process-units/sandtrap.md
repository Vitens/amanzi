# Sand trap

Library name: **Sand trap**. Hydraulic sizing of a grit / sand trap. **No quality transformation.**

## Place it when

You need a hydraulic element for a sand trap in the waste or raw-water line.

## Streams

- In/out: typically on a waste or raw path (library category: waste).

## Inputs (UI groups)

- Geometry and velocity / detention fields in the sand-trap design section.
- Temperature enters viscosity used for sizing.

## Outputs / design tables

- Hydraulic sizing numbers only.
- No PHREEQC change.

## Science

None required beyond [How Amanzi calculates](../../explanation/how-amanzi-calculates.md) (quantity/hydraulics only).
