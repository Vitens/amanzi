# Waste stream

Library name: **Waste stream**. The sink for a red line. The demo names it **Afvalstroom**.

## Place it when

A filter, a membrane, or another block has a waste outlet that must be connected. A required waste anchor left open keeps the scenario from being fully connected.

## Streams

In: waste. Nothing leaves. The flow that arrives here is part of the quantity loss, unless a [backwash reuse](recycle.md) block has already returned some of it to the product.
