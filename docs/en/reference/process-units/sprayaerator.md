# Spray aeration

Library name: **Spray aeration**. Droplet fall for CO₂ and CH₄ transfer.

## Place it when

You want spray/cascade-like gas transfer without a packed tower.

## Streams

- In/out: product.

## Inputs (UI groups)

- Fall height, RQ, droplet / Sauter diameter as exposed.
- Shared aeration sustainability fields.

## Outputs / design tables

- Removal fractions for the configured gases.
- Design sensitivity vs height and droplet size.
