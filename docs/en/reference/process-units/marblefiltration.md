# Marble filtration

Library name: **Marble filtration**. Contact filter on calcite (marble) with the same oxidation family as sand filtration, plus calcite saturation after steps.

## Place it when

You need filtration with pH / calcite buffering on marble, not only sand.

## Streams

- In: product.
- Out: product; flush (backwash).

## Inputs (UI groups)

- Filter geometry and spray aeration (shared with sand-style filtration).
- **Marble filter:** bed and marble-specific design fields.
- **Operational:** backwash programme.
- **Model:** oxidation-related options as exposed in the form.

## Outputs / design tables

- Design speciation with calcite saturation at steps.
- Hydraulic headloss and energy.
