# Results

What each result family in the sidebar and report displays, and in which units.

## Content to write

- **Quantity:** abstraction, distribution, loss (m³/h or matching production units).
- **Quality:** pH, hardness, Fe, Mn, NH₄, O₂, HCO₃, Cl, Na, SI, TACC₉₀ / CCPP, EGV/sc20, TDS, aggCO₂ — as labelled in the UI.
- **Energy:** kWh/m³ and kWh/year style totals where shown.
- **Chemicals:** dosed masses (g AS/m³ or as the table states).
- **Sustainability:** gCO₂-eq/m³, gCO₂-eq/year, specific vs total.
- Sidebar = current scenario after the last successful solve; report = all scenarios when you calculate the project.
- Invalid/empty state when the graph is not fully connected or the engine raises an error ([Limitations](limitations.md)).
