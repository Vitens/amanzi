# Reference

This catalog states what the public app contains: the window, the three streams, the result panels, the key figures, the units, and each library block. Why a number moves is in [Explanation](../explanation/index.md). How to change something is in the [how-to guides](../how-to/index.md). A first walk through the demo is in the [tutorials](../tutorials/index.md).

Parameter tables are the inputs stored for each block. Defaults and ranges are the values in `amanzi/parametric/`. A field marked as a fraction is stored from 0 to 1 even when its label says %.
