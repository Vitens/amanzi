# Glossary

Short definitions. No essays.

## Content to write

- **Scenario** — one version of the plant inside a project.
- **Project** — JSON file with one or more scenarios.
- **Flowsheet / canvas** — the drawing of units and streams.
- **Key figure** — shared lookup value (emission factor, limit, efficiency).
- **Abstraction** — groundwater source block.
- **Product / waste / flush** — the three stream types.
- **Backwash** — wash of a filter bed; often a flush stream.
- **EBCT** — empty bed contact time (GAC).
- **BV** — bed volumes.
- **GAC** — granular activated carbon.
- **RQ** — air-to-water ratio (aeration).
- **SI** — saturation index (calcite unless stated).
- **CCPP / TACC₉₀** — calcium carbonate precipitation potential / related UI label.
- **PHREEQC** — the chemistry engine Amanzi uses.
- **PFAS** — per- and polyfluoroalkyl substances.
- **Sum4 / Sum20 / PEQ** — grouped PFAS metrics (limits from key figures).
- **VOC** — volatile organic compounds (extraneous list).
- **RO / NF** — reverse osmosis / nanofiltration.
- **Kw** — membrane water permeability.
- **HTU / NTU** — height / number of transfer units (packed tower).
- **Freundlich K, 1/n** — isotherm parameters; 1/n is the exponent.
- **SRS** — Sheindorf–Rebhun–Sheintuch competitive Freundlich.
- **Pellet softening** — calcite pellet reactor (UI may say Pelletontharding).
