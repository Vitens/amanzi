# Set key figures

Set project-wide (and optional scenario) numbers that many calculations share: emission factors, PFAS limits, and similar lookup values.

## Content to write

- Open the **Key figures** tab in the right sidebar (and the key-figures dialog from the top bar).
- Project-level overwrites vs scenario-level overwrites: when a scenario should differ.
- When to touch a value: comparing CO₂ assumptions, or matching a regulatory Sum4/Sum20/PEQ limit — not for day-to-day flowsheet drawing.
- Search/filter in the key-figures list.
- Restore the built-in database value for one row.
- Facts about the database itself: [Key figures](../reference/key-figures.md).
