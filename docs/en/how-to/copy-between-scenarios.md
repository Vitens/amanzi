# Copy between scenarios
Selected Modelblocks (single or multiple) can be copied via the classic `Ctrl+C` and pasted in the same scenario canvas or into another scenario via `Ctrl+V`.
Copy and pasting multiple blocks also keeps the connections between them. 

Duplicating the current scenario can be done via the drop dwown menu at the top 

or the scenario menu at the bottom of the canvas





## Content to write

- Select one or more blocks; `Ctrl+C` / `Ctrl+V` (same on macOS with the usual modifier).
- Duplicate on the same canvas vs paste into another scenario tab.
- Connections: what copies with the block and what you must rewire.
- Scenario notes (v1.0.5): add, edit, they do not affect solvers.
- Rename or delete a scenario tab; you cannot leave the project with zero scenarios if the UI forbids it — document the actual rule.
