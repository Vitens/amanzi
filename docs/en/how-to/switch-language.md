# Switch language

Set the user interface to English, Dutch, or German.

## Content to write

- Where the locale control is (and that the default follows the browser language).
- The three locales: `en`, `nl`, `de`.
- What switches: library names, form labels, tutorial text, about dialog.
- This documentation site has the same three languages (English, Dutch, German) via its own language selector. It is a separate copy of the pages, not the app’s JSON catalog.
- What does **not** switch: project JSON field names, key-figure keys. Architecture documentation stays English.
- Some unit names stay mixed (example: pellet softening may appear as “Pelletontharding”).
