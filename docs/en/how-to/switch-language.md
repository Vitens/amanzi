# Switch language

Amanzi opens in the language of your browser. English, Dutch, and German are built in. The codes are `en`, `nl`, and `de`.

## Pick a language

The globe on the top bar shows **EN**, **NL**, or **DE**. Open it and choose one.

Menus, the library, result headings, and buttons follow that choice. **Main stream** becomes **Hoofdstroom** or **Hauptstrom**. **Key figures** becomes **Kengetallen** or **Kennzahlen**. **Calculate project** becomes **Bereken project** or **Projekt berechnen**. **Quality** becomes **Kwaliteit** or **Qualität**.

Names on the drawing stay as they are. On the demo plant, **Winning** and **Plaatbeluchting** stay those words. They are names stored in the project.

## Tutorial and About

**Help → Tutorial** and **Help → About Amanzi** use the language you picked.

In Dutch the tutorial is titled **Rondleiding**. It opens with **Welkom bij Amanzi!** and closes with **Aan de slag!**. About is **Over Amanzi**.

<video controls preload="metadata" src="../media/LanguageDialogs.mp4" style="max-width: 100%; height: auto;" aria-label="Open the tutorial in English, then in Dutch, then About Amanzi">
Open the tutorial in English, switch to Dutch, and open it again. Then open About Amanzi.
</video>

## Names change. Tags stay.

**Kengetallen** is the same list as **Key figures**. **Emission factor for electricity** becomes **Emissiefactor elektriciteit**. The tag stays `carbon_intensity_grid`. The column headings stay **Name**, **Tag**, **Default**, **Project**, **Scenario**, and **UOM**.

A downloaded project file keeps English field names as well, so a file from one language still opens in another. How to download it is in [Save, load, download](save-load-download.md).

<video controls preload="metadata" src="../media/KeyFigureLanguage.mp4" style="max-width: 100%; height: auto;" aria-label="Open key figures in Dutch, then in English, with the same tags">
Open Kengetallen. The names are Dutch and the tags stay English. Open the same list in English.
</video>

## This documentation

This site has its own choice: **English**, **Nederlands**, and **Deutsch**. Those are separate copies of these pages. Amanzi keeps its own list. The architecture documentation stays English.

## Another language

**Feedback?** opens an email to amanzi@vitens.nl. In German the button reads **Rückmeldung?**. Ask there for a language that is not in the list.
